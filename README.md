# DNS Switcher

DNS Switcher - программа для смены DNS на Windows 11 и macOS 12+. DNS с прокси используют для доступа к нейросетям и другим сервисам с геоблокировкой.

По умолчанию в списке доступны Bezmezhau DNS, DNS-AI, GeoHide (Россия) и Comss.one DNS.
Можно добавить свои или убрать ненужные. Доступность сайтов зависит от выбранного провайдера.

**[Скачать — GitHub Releases](https://github.com/eazyyz/dns-switcher/releases)**

## Windows - EXE

1. В разделе релизов скачайте `DNS-Switcher-Windows-Tray.zip` и распакуйте архив.
2. Запустите `DNS-Switcher.exe` — значок появится в трее, возможно под стрелкой скрытых значков.
3. Нажмите значок правой кнопкой мыши, выберите DNS и подтвердите запрос прав администратора. Дождитесь уведомления «Готово».

Активный DNS отмечен галочкой, его название видно при наведении на значок. Двойной щелчок показывает текущие настройки сети.
В меню можно вернуть автоматический DNS, изменить список и включить «Запускать вместе с Windows».
Перед включением автозапуска положите EXE в постоянную папку.

Недоступные адреса выбранного DNS пропускаются. Если после применения проверка подключения не проходит, программа пытается вернуть предыдущие настройки.

## Windows - BAT

1. В разделе релизов скачайте `DNS-Switcher-Windows.zip` и распакуйте архив.
2. Запустите `DNS-Switcher.bat` и подтвердите запрос прав администратора.
3. Введите номер нужного DNS и нажмите Enter. Дождитесь сообщения «Готово».

| Пункт | Действие |
| --- | --- |
| `1` | Вернуть автоматический DNS |
| `2` и далее | Выбрать DNS из списка |
| `E` | Изменить список DNS |
| `0` | Выйти |

## macOS

1. В разделе релизов скачайте `DNS-Switcher-macOS.zip` и распакуйте архив.
2. Перенесите `DNS Switcher.app` в «Программы» и откройте его — значок появится в строке меню.
3. Нажмите значок, выберите DNS и подтвердите запрос прав администратора. Дождитесь сообщения «Готово» в меню.

Активный DNS отмечен галочкой. В меню можно вернуть автоматический DNS, изменить список и включить «Запускать при входе».
Если macOS попросит разрешить автозапуск, подтвердите его в настройках системы.

Если macOS сообщает, что разработчик не проверен, откройте Терминал и выполните:

```sh
xattr -dr com.apple.quarantine "/Applications/DNS Switcher.app"
```

Затем снова откройте приложение. Команда снимает карантин только с DNS Switcher.

После выхода из любого варианта программы выбранный DNS продолжает работать.
Чтобы отключить его, запустите программу снова и выберите «Автоматический DNS» или `1` в BAT.

## Свои DNS

Выберите «Изменить список DNS…» в EXE или macOS, либо нажмите `E` в BAT, чтобы открыть `dns-user.txt`.
Можно добавлять, менять и удалять любые записи, включая стандартные:

```ini
[Мой DNS]
ipv4=181.215.40.49,31.58.216.201
ipv6=
doh=https://dns.bezmezhau.com/dns-query
```

`ipv4` и `doh` обязательны; `ipv6` можно оставить пустым. Адреса разделяются запятыми, а `doh` должен содержать HTTPS-адрес сервера DoH. Названия записей должны быть уникальными.

Сохраните файл в UTF-8. В EXE список обновится автоматически после закрытия меню; можно также выбрать «Обновить список».
На macOS откройте меню заново. В BAT вернитесь в окно программы и нажмите Enter.
Затем выберите нужный DNS для применения — само редактирование списка не меняет настройки сети.

Оба варианта Windows используют один список `%APPDATA%\DNS Switcher\lists\dns-user.txt`.
На macOS он находится в `~/Library/Application Support/DNS Switcher/lists/dns-user.txt`.

DNS меняется для подключений Wi-Fi и Ethernet. Если включён VPN или свой DNS в браузере, они могут использовать другие серверы.
