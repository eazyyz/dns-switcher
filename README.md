# DNS Switcher

DNS Switcher - Программа для смены DNS на Windows 11 и macOS 12+. DNS с прокси используют для доступа к нейросетям и другим сервисам с геоблокировкой.

По умолчанию в списке доступны Bezmezhau DNS, DNS-AI, GeoHide (Россия) и Comss.one DNS.
Можно добавить свои или убрать ненужные. Доступность сайтов зависит от выбранного провайдера.

**[Скачать — GitHub Releases](https://github.com/eazyyz/dns-switcher/releases)**

## Windows

1. В разделе релизов скачайте `DNS-Switcher-Windows.zip` и распакуйте архив.
2. Запустите `DNS-Switcher.bat` и подтвердите запрос прав администратора.
3. Введите номер нужного DNS и нажмите Enter. Дождитесь сообщения «Готово».

## macOS

1. В разделе релизов скачайте `DNS-Switcher-macOS.zip` и распакуйте архив.
2. Перенесите `DNS Switcher.app` в «Программы» и откройте его — меню появится в Терминале.
3. Введите номер нужного DNS и нажмите Enter. Появится запрос пароля, введите его и дождитесь сообщения «Готово».

Если macOS сообщает, что разработчик не проверен, откройте Терминал и выполните:

```sh
xattr -dr com.apple.quarantine "/Applications/DNS Switcher.app"
```

Затем снова откройте приложение. Команда снимает карантин только с DNS Switcher.

## Меню

| Пункт | Действие |
| --- | --- |
| `1` | Вернуть автоматический DNS |
| `2` и далее | Выбрать DNS из списка |
| `E` | Изменить список DNS |
| `0` | Выйти |

После закрытия окна выбранный DNS продолжает работать. Чтобы отключить его, запустите программу снова и выберите `1`.

## Свои DNS

Нажмите `E`, чтобы открыть `dns-user.txt`. Можно добавлять, менять и удалять любые записи, включая стандартные:

```ini
[Мой DNS]
ipv4=143.20.64.55,31.58.216.201
ipv6=
doh=https://dns.bezmezhau.com/dns-query
```

`ipv4` и `doh` обязательны; `ipv6` можно оставить пустым. Адреса разделяются запятыми, а `doh` должен содержать HTTPS-адрес сервера DoH. Названия записей должны быть уникальными.

Сохраните файл в UTF-8, вернитесь в окно программы и нажмите Enter. Затем выберите нужный DNS для применения. Обновление программы сохраняет ваш список.

DNS меняется для подключений Wi-Fi и Ethernet. Если включён VPN или свой DNS
в браузере, они могут использовать другие серверы.
